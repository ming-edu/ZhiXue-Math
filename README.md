# 智学数学 · 个性化学习原型

面向教师的"拍照识题 → 自动解题 → 自动批改 → 错题诊断 → 素养分析 → 变式训练 → 专题突破"闭环应用。

## 核心特点：每人数据独立

- **所有业务数据存在浏览器 localStorage**，不上传服务器、不共享。每个人打开链接看到的都是自己独立的一份，互不可见。
- **首次访问自动注入演示数据**（2 个班 80 学生）作为引导；首页一键「清空重置」回到空白起点，或「恢复演示数据」。
- **支持跨设备迁移**：首页「导出数据」把全部数据下载为一个 JSON 备份文件；换设备打开同一网址，点「导入数据」选择备份文件，即可「覆盖导入」接着用，或「合并导入」把另一台设备的数据并进来。
- **后端只做无状态 AI 能力**（识题、解题、看图批改、判分），不存储任何用户数据。AI 凭证存于后端 `ai_config.json`，不暴露给前端。

## 技术栈
- 后端：Flask（纯静态页面托管 + 无状态 AI 代理）
- 数据存储：浏览器 localStorage（`static/store.js`）
- 学情分析：前端 JS（`static/analyzer.js`，从原 Python 版移植）
- AI 视觉：硅基流动（SiliconFlow）Qwen3-VL-8B-Instruct
- 前端：原生 HTML/CSS/JS + Chart.js
- 知识图谱：北师大版(2024新课标)五上 + 2022 版课标核心素养

## 启动
```bash
cd /workspace/math-learning-demo
python3.11 app.py
# 浏览器打开 http://localhost:5000
```

## 功能模块

| 页面 | 功能 |
|---|---|
| 首页 `/` | 班级列表、数据状态提示、管理班级/清空重置/恢复演示数据、**导出数据 / 导入数据（跨设备迁移）**入口 |
| 班级管理 `/teacher/classes` | 建班级（自动生成唯一 8 位班号）、批量粘贴导入学生、删除学生/班级 |
| 学情看板 `/teacher/dashboard/<id>` | 统计概览、薄弱知识点排行、11 维素养雷达图、专题突破、学生逐人诊断 |
| 布置作业 `/teacher/create` | 三步向导：①拍照识题（设默认评分模式+默认分值）→ ②逐题核对、微调模式与分值 → ③预览确认 |
| 批改中心 `/teacher/review` | 自动判分结果、待复核队列、点学生看作业照片、人工改判 |
| 学生端 `/student` | 交整份作业拍照 AI 批改、单题提交、错题本、变式训练（答案可隐藏/重新出题）、个人学情 |

## 数据说明
- 演示数据：`static/demo_data.json`（2 班 80 学生、15 题、约 1800 条记录）
- 知识图谱：`static/kg.json`（36 知识点、11 素养、变式题模板）
- 首次访问时前端拉取这两个静态文件注入 localStorage；之后不再读取。
- 每个用户的 localStorage 完全独立，因此"数据隔离"无需账号即可实现。
- **备份文件**：`智学数学_数据备份_YYYYMMDD_HHMM.json`，含应用标识、导出时间、各表统计与全量数据。
  - **覆盖导入**：用备份完全替换本设备数据（换设备接着用的推荐方式，操作前会二次确认）。
  - **合并导入**：按班号/姓名/题目等稳定标识去重，并重映射外键 id，把另一台设备的数据并进来，不破坏原有班级关联。
  - 作业照片存于服务器，导入后仍可查看（需访问同一个应用网址）；导入前会展示备份摘要供核对，格式错误的文件会被拦截并提示。

## 评分模式
- **赋分制**：每题设分值，答对得满分、答错 0 分（AI 按最终结果判，步骤分可在批改中心手调）。
- **二元制**：只判正确/错误，不强调分数。
- 第一步设整份作业的默认值，第二步可逐题改个别题的模式和分值。

## 已知限制
1. **AI 不是万能**：免费小模型对复杂图形题、潦草手写偶尔出错，老师核对答案那一步不可省；批改中心可复核修正。
2. **数据默认跟浏览器绑定**：换设备请用首页「导出数据」→ 新设备「导入数据」迁移；作业照片存服务器，迁移后需访问同一应用网址查看。
3. **调用费用**：使用硅基流动，额度以官网为准；换模型改 `ai_config.json` 的 model。
4. **变式题**：参数化模板生成，题型有限，非大模型自由出题。
5. **知识追踪**：简单正确率聚合，未上 BKT/DKT 时序模型。

## 维护脚本

- `python3.11 export_static.py`：把 SQLite 演示数据 + 知识图谱导出为静态 JSON（改动演示数据后需重新导出并发布）
