# 智学数学 · 个性化学习原型

面向教师的 AI 作业批改与学情诊断工具。**纯静态应用**，无需服务器：

- 打开 [index.html](index.html) 进入应用
- 所有数据保存在你自己的浏览器（localStorage），不同设备/浏览器互不相见
- 支持「导出数据 / 导入数据」跨设备迁移

## AI 功能（拍照识题、整页批改）
1. 点右上角 **AI设置**，填入你自己的硅基流动 API Key（[免费申请](https://cloud.siliconflow.cn/account/ak)）
2. Key 只存在你自己的浏览器里，不上传、不共享；费用走你自己的账户（注册送免费额度）
3. 单题规则判分不需要 Key

提示：本应用为静态站点，学生拍照批改不会把照片上传到服务器；作业照片仅在本次批改中使用。
